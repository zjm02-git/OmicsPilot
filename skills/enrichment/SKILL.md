# 通路富集分析（Enrichment Analysis）

## 做什么
给一组显著基因 + 基因-通路注释表，判断显著基因是不是「扎堆」在
某些通路 / GO term 里（而不是随机分布）。

## 怎么做
1. **准备三样**：显著基因列表、注释表（gene / term 两列）、背景基因全集（通常 = 表达矩阵所有基因）。
2. **超几何检验**（抽球比喻）：袋里 N 个球，K 个红球（某通路基因），随手抽 n 个（显著基因）里有 k 个红球；k 明显比瞎抽多 → 该通路富集。
3. **BH 校正**：一次查很多通路，也要做多重检验校正。
4. **出结果**：按 FDR 排序，标出显著富集的通路 + 富集到的基因。

## 对应代码
- 纯计算在 `omics_agent/enrichment.py` 的 `enrichment_analysis()`（优先 scipy 超几何，没 scipy 退化为对数递推实现）。

## 常见坑
- 背景基因必须用「所有测过的基因」，不能只用显著基因，否则通路比例全错。
- 注释表很大（几十万行）时，按 term 分组算，别在循环里反复全表过滤。
